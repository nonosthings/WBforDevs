# HOW TO CONTRIBUTE A NEW BLOCK TO WIDGETBLOCKS

 1. Edit `ExampleContributorBlock` below to build and test your custom block inside "WB for Devs".
 2. Set `blockId`, `title`, `subtitle`, `symbol`, and your `authorGitHubHandle`.
 3. Run "WB for Devs" in Xcode, tap "+", and add your block from the "Add Block" sheet to test
    its sizing, contrast, alignment, and Home Screen / Desktop widget rendering.
 4. Once your block passes the accessibility & contrast checks, submit your block file in a Pull Request!

**WARNING**
Before submitting, please refer to the Human Interface Guidelines (see https:developer.apple.com/design/human-interface-guidelines) and App Store Guidelines (https:developer.apple.com/support/terms/) as checks will be done to ensure your code doesn't violate these guidelines.
Please make sure that:

 1. Your code is original, meaning little to no AI generation is used or is indicated.
 2. Your block isn't already existing in the app, either from the creator or by another user.
 3. Your code doesn't do anything malicious, such as making requests to servers that can steal information, damage devices, or run arbitrary code.
 4. Your block actually works.
 5. Your block passes the accessibility & contrast check.
 6. You go have fun and make your idea come to life! :)
